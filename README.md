# PollyPocket

Appli web installable (PWA) : salaire perso ou à deux, revenus en plus, charges fixes avec historique, dépenses par catégorie et par semaine, enveloppes avec alertes, épargne et tickets resto.

- Les données restent sur le téléphone (localStorage). Bouton Exporter/Importer dans l'onglet Budget pour les sauvegardes.
- Hébergement : GitHub Pages, branche `main`, dossier racine.
- Après une modification, incrémenter `VERSION` dans `sw.js`.

Installation : ouvrir le lien dans Safari (iPhone) ou Chrome (Android), puis « Sur l'écran d'accueil » / « Installer l'application ».
